# 01. Industrial Visit Context

## Visit Period

2026.09.18–19

## Companies

- NEPES
- Hyundai Steel

## What I Directly Experienced

이번 산업시찰에서는 두 회사의 실제 사업장을 방문해 기업 설명을 듣고, 제조 현장이 운영되는 모습을 관찰했다.

NEPES:
- 반도체 관련 사업과 생산 현장 설명
- 후공정 / packaging / process-material business에 대한 현장 이해
- 실제 제조기업의 조직과 업무가 어떻게 연결되는지 관찰

Hyundai Steel:
- 실제 생산이 진행되는 제조현장 관찰
- 고온의 쇳물 / 철강 반제품이 만들어지고 다음 공정으로 이동하는 흐름 확인
- 대규모 설비와 물류가 연속 생산을 지탱하는 현장 경험

## Portfolio Focus

이 저장소는 두 방문지를 동등하게 소개하지 않는다.

반도체 공정 / 양산 / 품질 직무를 준비하는 목적에 맞춰 NEPES를 중심으로 정리하고, 현대제철은 대규모 제조 시스템의 공통 원리를 비교하는 보조 사례로 사용한다.

## What Was Added After the Visit

현장 경험만으로는 구체적인 공정·직무 구조를 모두 기록할 수 없었기 때문에, 포트폴리오 작성 과정에서 NEPES 공식 사업자료와 현재 채용공고를 추가 조사했다.

따라서 각 문서에서는:

- 직접 현장에서 본 것
- 공식 회사자료로 확인한 것
- 내가 취업 관점에서 해석한 것

을 구분한다.
